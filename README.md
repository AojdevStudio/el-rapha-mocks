# El Rapha Groups — website mocks

Four homepage concepts for Sunday Osogbuyi / El Rapha Groups, plus the inner pages each direction needs next. Same brand colors (matte navy and soft gold). Different layout, voice, and information architecture.

Open `index.html` for the review board.

| Concept | Path | What leads |
| --- | --- | --- |
| A · The House | `mocks/a/` | Two equal doors: bookkeeping and home care |
| B · The Ledger | `mocks/b/` | Bookkeeping firm; home care is the sister practice |
| C · At Home | `mocks/c/` | Home care; bookkeeping is the companion practice |
| D · Start Here | `mocks/d/` | Intake and booking above the fold |

Forms are previews. They confirm on the page and do not send data. There is no login and no live portal.

The public URL, once Pages is on, is https://aojdevstudio.github.io/el-rapha-mocks/

Publishing needs one setting this repository's admin can save. The files are already on `main`.

1. Open the repository Settings, then Pages.
2. Under Build and deployment, set Source to **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then Save.

GitHub publishes the root `index.html` from that branch. No build step.
